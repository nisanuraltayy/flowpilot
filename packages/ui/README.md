# packages/ui — Design System

Frontend'in paylaşılan görsel dili.

## İçerik (üretilecek)

- Token tabanlı renk, spacing, typography
- Tek form component standardı
- Tek error/message standardı
- Ortak status badge katalogu
- Zorunlu ekran state'leri için ortak bileşenler: loading/skeleton, empty, permission-denied, not-found, error

## Sınırlar

- **İş mantığı içeremez.** Yetki kararı, koşul değerlendirmesi veya onay sırası burada bulunamaz.
- **Domain status rengi tek başına bilgi taşımaz** — renk körlüğü ve erişilebilirlik için metin/ikon eşlik eder (WCAG 2.1 AA hedefi).
- UI metinleri **i18n anahtarlarıyla** tutulur (TR/EN).
- Tarih ve para formatı **locale-aware**dır.
